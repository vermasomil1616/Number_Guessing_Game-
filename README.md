# 🎮 Number Guessing Game - Java GUI

This is a simple Java Swing-based **Number Guessing Game** developed as part of **CodSoft Internship Task 1**.

## 🚀 Features

- 🔢 Random number between 1 to 100
- ⌛ Limited to 5 attempts per round
- 🎯 Feedback: "Too high", "Too low", or "Correct"
- 🔁 Play multiple rounds
- 🏆 Score tracked across rounds
